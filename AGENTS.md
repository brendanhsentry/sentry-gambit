# Coding conventions

- Do not add tests unless you encounter the regression during your work.
- Avoid comments unless absolutely necessary. Use them sparingly, and keep every comment to one line.

# General

- Always work inside a worktree (pull main first) for code changes, and remove the worktree once done.
- No need for PRs, merge to main.
- Other agents are working on this repo, there will be frequent merge conflicts.
- Always squash and merge.
